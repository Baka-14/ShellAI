{

  "constraints": {

    "earliest_start_time": "<HH:MM or null>",
    "department": "<department code, e.g. CMSC>",
    "grad_level_only": <true/false>
  },
  "social": {
    "wants_study_partners": <true/false>
  }
}

Rules:
- Return ONLY valid JSON. No markdown fences, no commentary.
